# Linux 的历史

## 学习目标

- 了解 Linux 的诞生背景
- 掌握 Linux 发展的重要里程碑
- 理解开源运动的发展历程

## 1. 前史：Unix 与 GNU

### 1.1 Unix 的诞生（1969）

- 1969 年，贝尔实验室的 Ken Thompson 和 Dennis Ritchie 开发了 Unix
- Unix 最初用汇编语言编写，后改用 C 语言重写
- Unix 的设计哲学影响了后来的许多操作系统

### 1.2 GNU 项目的启动（1983）

- 1983 年，Richard Stallman 发起 GNU 项目
- 目标：创建一个完全自由的类 Unix 操作系统
- 1985 年，发布 GNU 宣言
- 1989 年，发布 GNU 通用公共许可证（GPL）

## 2. Linux 的诞生

### 2.1 Linus Torvalds

- 1991 年，芬兰赫尔辛基大学学生 Linus Torvalds 开始编写 Linux 内核
- 最初只是一个终端仿真器，后来发展为完整的操作系统内核
- 1991 年 9 月 17 日，Linux 0.01 版本发布

### 2.2 著名的 comp.os.minix 邮件

## 3. Linux 的发展

### 3.1 早期发展（1991-1994）

- 1991 年：Linux 0.01 发布
- 1992 年：Linux 采用 GPL 许可证
- 1994 年：Linux 1.0 发布

### 3.2 商业化发展（1995-2000）

- 1995 年：Red Hat Linux 发布
- 1996 年：SUSE Linux 发布
- 1998 年：IBM、Oracle 等大公司开始支持 Linux
- 2000 年：Red Hat 在纳斯达克上市

### 3.3 现代发展（2001-至今）

- 2004 年：Ubuntu 发布，推动 Linux 桌面普及
- 2007 年：Android 基于 Linux 内核发布
- 2010 年后：云计算、容器技术兴起，Linux 成为主流
