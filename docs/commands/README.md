# 命令篇

Linux 命令参考手册，按功能分类整理，供其他章节交叉引用。

## 使用说明

本篇提供常用命令的详细说明和示例，读者可以在学习其他章节时快速查阅相关命令。

## 章节组织

- **基本命令**：文件和目录的基本操作
- **文本处理**：文本编辑、搜索和处理
- **系统管理**：系统监控、进程管理
- **网络管理**：网络配置和诊断
- **包管理**：软件安装和管理

## 命令格式约定

```
命令 [选项] [参数]
```

- `命令`：要执行的命令
- `[选项]`：可选的命令选项
- `[参数]`：命令的操作对象

## 常见选项约定

- `-a`：显示所有信息
- `-l`：长格式显示
- `-r`：递归操作
- `-v`：详细输出
- `-f`：强制执行
- `-i`：交互式操作
